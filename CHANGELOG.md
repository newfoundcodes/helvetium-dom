# Changelog

## 0.1.0 - 2026-09-05

Initial implementation under the Helvetium DOM name.

### Added

- VNode creation and normalization.
- Element, text, fragment, component, and portal VNodes.
- Keyed reconciliation and multi-node range moves.
- DOM props, attributes, styles, refs, and stable native event invokers.
- Function components and hooks.
- Context, `memo`, and `forwardRef`.
- Microtask scheduler, batching, and synchronous flush API.
- JSX automatic runtime.
- SSR and static markup rendering.
- Marker-aware hydration and recoverable mismatch reporting.
- Unit tests, examples, architecture/security/performance documentation.
- Independent Node.js built-in test harness with no external browser-simulation dependency.
- Package identity `@newfoundcodes/helvetium-dom`.
